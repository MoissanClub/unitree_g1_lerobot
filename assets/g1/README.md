# G1 Assets

`g1_body23.urdf` is vendored from Unitree's LeRobot evaluation assets:

https://github.com/unitreerobotics/unitree_lerobot/blob/main/unitree_lerobot/eval_robot/assets/g1/g1_body23.urdf

It references the same `meshes/*.STL` layout already present in the cached
`lerobot/unitree-g1-mujoco` Hugging Face asset snapshot, so this repo does not duplicate
the mesh files.
